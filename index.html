All-in-One File Converter

Simple tools for documents, images, HTML and JSON

Important: This is a single-file browser tool. HTML ↔ JSON and JPG/PNG conversion work locally. PDF/Word conversions need extra libraries or a server and are not fully supported offline here; use the relevant tools below where available. Your files are processed in your browser for the supported conversions.

HTML → JSON

Wrap HTML markup as JSON text and download it.

JSON → HTML

Extract HTML stored in a JSON string or an object with an “html” field.

JPG / JPEG → PNG

Convert an image to PNG format in your browser.

PNG → JPG

Convert PNG images to JPG with a white background.

Image → WebP

Convert common image formats to compact WebP.

Image → PDF

Place an image on a printable page and save as PDF using your browser’s print dialog.

PDF → Images

Open a PDF and use your PDF viewer’s export or screenshot options to save pages as images.

DOC / DOCX → PDF

Open a Word document in Word or Google Docs, then export/download it as PDF.

DOC / DOCX → Image

Convert via PDF first, then export each page as an image using a PDF app.

Text → TXT

Save text entered below as a plain text file.

JSON Formatter

Validate and neatly format JSON text.

HTML Preview

Preview pasted HTML in a separate tab. Only preview content you trust.
